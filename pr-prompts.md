# AI Review Prompts

Use these prompts during the lesson.

## General PR Review

```text
Review this pull request as a code reviewer.
Focus on real bugs, unclear code, missing checks, and unnecessary complexity.
Do not discuss merge conflicts.
```

## Beginner-Friendly Review

```text
Review this diff for a beginner Python project.
Explain any important issue briefly and suggest a small fix.
Do not suggest large refactors unless they are needed for correctness.
Do not discuss merge conflicts.
```
